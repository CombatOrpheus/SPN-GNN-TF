## 2024-05-14 - tf.data.Dataset Caching Optimization
**Learning:** Adding `.cache()` to TensorFlow dataset pipelines is a powerful optimization but introduces significant ML bugs if applied after `.shuffle()`, as it freezes the shuffling order across all epochs. Additionally, using `.cache()` without a filename caches unbounded datasets directly into memory, which crashes the system with Out-Of-Memory (OOM) errors on large datasets. Stale `.cache*` files on disk can also cause tests to fail if the dataset structure changes between runs.
**Action:** When adding caching to `tf.data.Dataset`, always provide a file path (e.g., `.cache(file_path + ".cache")`) to utilize disk caching instead of memory, and ensure it is placed *before* any stochastic operations like `.shuffle()` to preserve epoch-level randomness. Remember to clear `*.cache*` files if tests fail unexpectedly.
